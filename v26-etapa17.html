Mega Passos V26 — Etapa 17

Registro estruturado e conferência de rankings congelados.

1 — Registrar previsão

Copie da V25 os rankings completos de dez dezenas, mantendo a ordem apresentada.

2 — Registro gerado

Copie e publique o JSON no GitHub antes do sorteio, caso queira documentar antecipadamente a previsão. A data de geração local não comprova publicação anterior.

3 — Conferir previsão registrada

Cole o JSON completo salvo anteriormente. A conferência usa somente as dezenas contidas nele, sem recalcular rankings.

Regras da auditoria

O sistema verifica se o JSON está completo, se o concurso-alvo corresponde ao treinamento informado, se cada modelo contém dez dezenas válidas e distintas e se o resultado contém seis dezenas distintas.

A conferência demonstra apenas os acertos das listas fornecidas. Não autentica a data de publicação, não prova que os rankings foram produzidos pela V25 e não demonstra vantagem preditiva.
